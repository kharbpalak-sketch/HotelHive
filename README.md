#  🛋️ HotelHive

**HotelHive** is a backend-driven Hotel Management System developed using **Python** and **SQL**, designed to handle core hotel operations efficiently.
The project focuses on real-world backend functionality, including **database connectivity**, **data management**, and **booking operations**.

---

## 🚀 Key Highlights

* 🔗 Seamless **Python–SQL Integration**
* ⚙️ Backend logic for real-time hotel operations
* 💾 Persistent data storage using SQL database
* 📊 Structured handling of customer & booking data

---

## ✨ Features

* 🛏️ Room Booking Management
* 👤 Customer Data Handling
* 📋 Booking Records Management
* 🔍 Room Availability Check
* 🔄 Booking Rescheduling
* 📤 Export Data to CSV
* 🗄️ CRUD Operations (Create, Read, Update, Delete)

## ⚙️ Installation & Setup

### 1. Clone the Repository
git clone https://github.com/kharbpalak-sketch/HotelHive.git  
cd HotelHive  

### 2. Install Dependencies
pip install -r requirements.txt  

### 3. Setup Database
- Import the `database.sql` file into your SQL database  
- Update `.env` with your database credentials  

### 4. Run the Project
python server.py
